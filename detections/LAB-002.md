# LAB-002: Notepad Demo Process Started

Platform: LimaCharlie D&R. Purpose: validate an endpoint process-start detection with a benign, controlled action. Use [the exported YAML](LAB-002.yaml), which includes the detect/respond sections and two synthetic test fixtures.

The rule combines a case-insensitive executable suffix match with a case-insensitive command-line substring match. Response: `report`, named `LAB-002 Notepad Demo Process Started`. It does not terminate processes or isolate devices.

## Validation

The two fixtures passed in the rule test interface. A new launch on the Windows VM generated a live detection on 2026-10-02 at 16:05:30.691 UTC. See [SOC-L1-002](../cases/SOC-L1-002-edr-notepad.md).

## Coverage and limits

This is a lab rule, not a malware detector. It matches a command-line substring, not a parsed exact argument, and it is not restricted to one sensor. Another sensor producing the same values could match. Alternative path spellings or programs opening the same file can be missed. A matching filename in an argument does not prove successful read/write. The two fixtures are a small validation set and do not establish production detection coverage or false-positive rates.
