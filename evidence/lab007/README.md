# LAB-007 evidence inventory

Four screenshots supplied by the operator were copied from their original clipboard files to the local evidence folder and then copied to this repository without byte changes. The HTTPS text is explicitly labeled as a chat transcript, not a direct terminal export. The packet summary was generated by tshark from the operator-exported local PCAPNG.

| Artifact | Scope |
|---|---|

| [TCP handshake](LAB-007-tcp-handshake.png) | Separate fixed-IP TCP test using client port 51919 |
| [TLS Client Hello](LAB-007-tls-client-hello.png) | SNI example.com and destination 104.20.23.154 |
| [TLS stream](LAB-007-tls-stream.png) | Original stream 229, client port 60000 |

The raw file `LAB-007-example-tls.pcapng` is retained locally in `soc-transfer-lab`, outside the repository. It is excluded by the existing PCAPNG ignore rule. No TLS session keys were collected. Initial unfiltered capture and unrelated background traffic were not included.
